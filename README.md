# 字时光

一个适合 iPhone 使用的识字复习最小版本。无需注册，数据保存在设备本地。

## 本地预览

在此目录启动任意静态文件服务器，然后访问 `index.html`。例如使用 VS Code 的 Live Server。

## iPhone 使用

部署到任意 HTTPS 静态网站后，用 Safari 打开，点击“分享”→“添加到主屏幕”。

## 已实现

- 按日期批量录入汉字，可添加记忆提示
- 自动筛选今天需要复习的字
- 卡片点击提示、左右滑动互动
- 点击喇叭使用设备中文语音朗读当前汉字
- 录入字库按日期分组、筛选并统计字数
- 自动记录每日实际复习字库，可按日期查看和统计
- 完成后可重复复习同一组字，评级时播放个性化鼓励语
- “课本识字”按小学一至六年级、上下册记录识字表，并可筛选整册随时复习
- 识字表可按课时再次编辑，支持任意组合课时并临时打乱顺序复习
- “再练练 / 有点熟 / 掌握了”三级评价
- 根据评价安排当天、2 天后、7 天后复习
- 字库、课本识字、复习记录、等级和连续天数均保存在本机
- 页面联网时自动检查新版本，离线时继续使用缓存版本
