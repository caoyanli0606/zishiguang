# 字时光

一个适合 iPhone 使用的识字复习最小版本。无需注册，数据保存在设备本地。

## 本地预览

在此目录启动任意静态文件服务器，然后访问 `index.html`。例如使用 VS Code 的 Live Server。

## iPhone 使用

部署到任意 HTTPS 静态网站后，用 Safari 打开，点击“分享”→“添加到主屏幕”。

## 已实现

- 按日期批量录入汉字，可添加记忆提示
- 自动筛选今天需要复习的字
- 卡片点击提示、左右滑动互动
- “再练练 / 有点熟 / 掌握了”三级评价
- 根据评价安排当天、2 天后、7 天后复习
- 连续复习天数与本地离线保存
- 家庭口令连接云端，同一口令可在多个设备同步

## 开启云同步

按照 `CLOUD_SETUP.md` 创建免费 Supabase 数据库并填写 `cloud-config.js`，然后重新发布到 GitHub Pages。
